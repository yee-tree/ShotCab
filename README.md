## 启动

运行 `ShotCab.exe`，从系统托盘打开菜单；双击托盘图标会呼出侧栏，完整历史仍从侧栏或托盘菜单打开。
默认快捷键：F6 截图、F7 贴图、F8 显示或隐藏照片栏、F9 OCR 截图。
快捷键可在设置中修改；占用时显示提醒。

F6 拖动完成选区后直接保存历史、复制并切到近期列表，无需再次确认。按 Esc 取消。
托盘“自由形状截图”可沿任意轮廓拖动，选区外像素不会纳入结果；“上次区域”会按上一次手动区域截图的屏幕坐标再次截取，取的是当前屏幕内容，并非再次复制旧图。自由形状截图的“上次区域”使用其外接矩形。这个位置只记在本次运行中，重启后须先截一次区域。
截图完成后短暂显示“结果条”，提供编辑图片、贴图、识别文字和打开文件的后续操作；
它不是保存确认框，关闭结果条也不会删除截图。可在侧栏“设置 → 截图”关闭显示。
开启“截图后直接编辑”时，也会先保存原截图，再打开编辑器；关闭编辑器不会丢掉已截图片。
需要修改时，右键历史卡片选择“修改”。编辑器窗口不使用系统标题栏：
顶部自绘标题栏显示图片尺寸与缩放比例，右侧是窗口按钮；
底部横向工具栏与编辑器同宽。常用标注、撤销/重做、关闭和“完成并复制”都是单色图标，悬停显示作用。
底栏的历史图标按需展开编辑器右侧的步骤面板；点击任一步可返回该次编辑状态，再次编辑会舍弃未采用的后续步骤。该步骤历史只属于当前编辑会话，重新打开图片后从新会话开始。
编辑器默认进入“选择”工具，使用普通鼠标指针；绘图工具使用绘图光标。
右键矩形、椭圆、线条、箭头、气泡框等工具，可调整颜色、线条粗细和可用的内部填充，线条粗细可输入 0–50 像素的自定义值。点击其他绘图工具会收起当前样式面板。气泡框及形状支持透明填充、保留边框。选中已有标注后，也可通过“标注颜色与线条”调整该对象。更改对象样式可撤销。
点击“更多”会在底栏展开第二行，包含其他标注、颜色、样式与高级操作。“取样覆盖”放在“其他标注工具”中：它用起点像素的单一颜色覆盖矩形，适合纯色背景清除小瑕疵，不会按周围纹理智能修复，也不能代替隐私打码。图片周边为实色背景；
常用栏直接提供直线、曲线箭头和文字框；第二行有独立的“图片拼接”图标。编辑器中拼接时，当前编辑结果作为第一张，只需再选一张图片及横向/纵向排列；拼接作为一步编辑可撤销。也可以在侧栏右键一张历史图片选择“拼接另一张图片”，或从托盘依次选择两张图片，无需在文件对话框中同时多选。
拖动标题栏可移动窗口，四边与四角仍可缩放。
侧栏默认宽 320 个逻辑像素，可缩到 180 个逻辑像素，并固定在屏幕右侧；右上角 × 隐藏侧栏，F8 可重新打开。
侧栏“设置”包含六类：截图、历史、外观、常规与快捷键、存储、OCR/其他。原“详细设置”中的选项已归入这些类别；选项较多时可用滚轮滚动。部分开关右侧的圆形 i 悬停后解释开启前后的行为。“外观 → 默认标注样式”按需展开，修改后立即保存。托盘中的“设置”也会打开同一侧栏。
照片栏单击复制，拖动复制到其他应用；也可把图片文件或位图拖入“近期”“历史”的内容区域，直接导入为独立历史记录。右键可修改、收藏、标签、隐藏或删除。
“近期”和“历史”均支持 Ctrl+单击增减选中、Shift+单击按当前可见顺序选择范围。选择多张后，可点击底部的批量操作入口，或右键已选卡片，统一收藏、设置标签、隐藏或移入回收站；普通单击仍复制单张图片。
剪切仅剪切临时导出文件，内部历史保留。

历史默认保存 7 天，回收站保留 3 天，收藏免于自动到期清理。
图片保存在数据目录的 `items/记录ID/版本/` 子目录，`current.png` 是合成图片、`original.png` 是可编辑底图；SQLite 只存索引与文字元数据。
右键卡片选择“打开图片所在文件夹”可定位实际文件。需要交给其他软件修改的普通副本，可使用“导出”。
完整历史窗口将筛选、列表与预览、批量操作、存储管理分区展示；日期筛选和截图时间完整显示，并支持批量操作与数据目录迁移。
普通马赛克保留内部原图；“永久应用遮挡”不可撤销，且不会影响其他已导出的副本。

安装版可在安装向导中选择是否一并安装离线 OCR；安装后使用默认路径，无需手动选择程序。
便携版可单独构建 OCR 增强包，在“设置 → OCR/其他”选择其中的 `ShotCab.Ocr.exe`。
必须保留增强包完整目录。无需 Python；识别结束后工作进程退出。
图片编辑器底栏有直接识别按钮；“设置 → OCR/其他”也可开启进入编辑器时自动识别。结果在同一窗口右侧显示实时字数，可修改；图片文字可拖选，并通过 Ctrl+C 或右侧复制按钮复制，不另开选字窗口。
托盘 OCR 截图和历史图片选字仍使用独立选字窗口，支持图上拖选、跨行选择、文字编辑和复制后预览。
按用户安装包已提供可选 OCR 组件；安装目录与运行数据目录分离，卸载保留截图历史。
本版核对记录见 `docs/release-1.0.0.md`；安装器原型与迁移注意事项分别见 `docs/installer-release.md`、`docs/installer-plan.md`。

## 构建与检查

需要 Windows、.NET SDK 和 .NET Framework 4.8。

```powershell
./scripts/build.ps1
./scripts/build.ps1 -Project tests/ShotCab.Core.Tests/ShotCab.Core.Tests.csproj -Test
./scripts/build.ps1 -Project tests/ShotCab.Editor.Tests/ShotCab.Editor.Tests.csproj
./tests/ShotCab.Editor.Tests/bin/Release/net48/ShotCab.Editor.Tests.exe
./scripts/build-ocr.ps1
./scripts/build-installer.ps1 -NsisPath 'F:\path\to\makensis.exe'
```

脚本将 NuGet、临时文件与构建缓存定位到本项目 `.cache`，产物在 `artifacts`。
直接运行未经脚本配置的 SDK 命令可能使用系统默认缓存目录。
