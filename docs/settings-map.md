# 侧栏设置分类

设置仅保留六个顶层入口。内容超出侧栏高度时可用滚轮滚动；默认标注样式按需展开。

| 入口 | 设置内容 |
| --- | --- |
| 截图 | 截图时隐藏面板、截图后编辑、结果条、放大镜与坐标、导出格式、JPG 质量、编辑历史时另建记录 |
| 历史 | 保存历史、保留天数、近期张数、回收站保留天数 |
| 外观 | 主题、侧栏开关、宽度、停靠侧、显示器、预留空间、自动折叠；可展开的默认标注样式包含形状、线条、文字、气泡、序号和效果 |
| 常规与快捷键 | 语言、全屏时行为、预览卡片拖出按键、四组全局快捷键、开机启动 |
| 存储 | 图片文件夹、容量提醒、存储管理及数据目录迁移 |
| OCR/其他 | 离线 OCR 程序路径、识字预览时间、退出应用 |

常用设置与默认标注样式的修改即时保存。标注颜色支持透明填充；编辑器内的工具样式色块和粗细也在点击时立即生效。
