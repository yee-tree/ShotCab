ShotCab / 图柜

安装器只安装程序文件、运行依赖和许可说明，不包含开发者的截图、设置、缓存或构建文件。
安装时可以单独勾选“离线 OCR”；未勾选时截图、历史和编辑仍可正常使用。
安装版的新用户数据默认保存在当前用户的 LocalAppData\ShotCab\Data。
卸载程序只移除安装器放入的程序文件和快捷方式，保留截图历史及用户设置。
如需清理历史，请先在 ShotCab 的历史与存储管理中操作，或自行确认数据目录后删除。
程序需要 Windows x64 和 .NET Framework 4.8 或更新版本。

This installer contains only application files, runtime dependencies, and license notices.
It does not include the developer's screenshots, settings, caches, or build files.
Offline OCR is an optional component selected during setup; core capture and editing work without it.
For a new per-user installation, data is stored under LocalAppData\ShotCab\Data.
Uninstall removes program files and shortcuts while preserving your screenshots and preferences.
ShotCab requires Windows x64 and .NET Framework 4.8 or later.
