# ShotCab 1.0.0 发行核对

## 本次变化

- 侧栏“近期”和“历史”支持 Ctrl+单击逐项增减、Shift+单击按可见顺序选择范围；普通单击仍复制单张图片。
- 多选时底部显示选中数量；点击底部或右键已选卡片，可批量收藏、取消收藏、设置标签、隐藏或移入回收站。批量删除前会再次确认。
- 源码清单中没有本机 UI 参考目录；公开文档中与该目录有关的名称也已移除。
- 主程序、安装器文件版本和卸载注册表版本统一为 `1.0.0`。OCR 仍是默认不勾选的离线可选组件。

## 本机验证

- 10 项核心测试通过，包括新增的 Ctrl/Shift 选择范围与刷新后选中状态测试；编辑器测试通过。核心迁移测试曾遇一次已知的 Windows 临时目录“访问被拒绝”，随后顺序重跑通过。
- Release 构建无错误；上游 `.resx` 重复资源名警告仍存在。主程序文件版本为 `1.0.0.0`，安装器版本为 `1.0.0`。
- 安装载荷为 233 个文件，逐项 SHA-256 与清单匹配。只有程序运行文件、用户说明、许可声明和可选 OCR 进入载荷；没有本机 UI 参考目录、开发缓存、测试、历史或个人设置。
- 从 1.0.0 精简载荷执行离线 OCR 实测，混合中文/英文识别、逐字坐标、取消、选字窗口及编辑器自动识别均通过。
- 运行中的 ShotCab 存在时，1.0.0 安装器静默启动返回错误码 2，未创建安装目录。0.1.0 的完整安装、OCR、升级及卸载验证见 [安装器原型记录](installer-release.md)；因本机仍运行用户的 ShotCab，本轮没有覆盖其进程执行 1.0.0 的实际安装。

安装器未签名；干净 Windows 10/11、真实用户历史迁移、交互式组件页和不同磁盘余量仍待验证。本记录仅说明本机已核对的范围。
